## CCBOX 首个双平台开源版

- Windows x64 与 Apple Silicon Mac 原生图形应用。
- 保留独立账号空间、代理、多项目挂载、持久化登录与沙箱 VS Code。
- 可选本机开发，通过逐次确认命令复用本机工具链；模型和登录仍在容器。
- 中文使用指南、架构边界、源码检查及双平台构建流程。

### 下载

- Windows：下载 `CCBOX-windows-x64.zip`，完整解压后运行 `CCBOX.exe`，保留旁边的 runtime。
- M 系列 Mac：下载 `CCBOX-macos-arm64.zip`，将 `CCBOX.app` 放入应用程序。
- 两端均需自行安装并启动 Docker Desktop；初次下载镜像和编辑器需要网络。
- 核验 `SHA256SUMS.txt`；各平台验证详情见 `verification-*.json`。

### 更新现有安装

关闭 CCBOX 并保留数据备份。Windows 合并程序与 runtime 到原目录，保留旧 data 与 storage-location.json；Mac 替换应用，不清空 Application Support / Keychain。配置与登录卷不随本次发布迁移或删除。

### 已知边界

Mac 当前为 ad-hoc 签名且未 Apple 公证；Windows 未做 Authenticode 签名。首次打开按系统提示核对来源，不关闭整体安全检查。

CI 验证单元测试与打包 / 解压自检，不包含真实 Claude 登录、付费模型请求、完整 Docker 链路或 Mac 真钥匙串持久化。本机模式以当前系统用户权限执行，使用本机网络；项目目录不是系统沙箱。本工具不承诺匿名性或账号状态。
