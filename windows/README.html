CCBOX 0.3.3 · 开始使用

选账号、选项目，打开独立开发空间。已打包版本自带 Python，无需自行制作。

  1. 安装并启动 Docker Desktop，使用 Linux 容器。Mac 选择 Apple silicon 版本。
  2. Windows 完整解压后双击 CCBOX.exe，保留旁边的 runtime；Mac 将 CCBOX.app 放入应用程序。
  3. 在 CCBOX 选择独立空间、项目目录和代理，保存并测试。
  4. 保持默认“沙箱开发”，点击“打开 / 恢复 VS Code”。首次镜像和编辑器下载需要等待。
  5. 核对自己的项目可信后，在沙箱内完成 Claude 官方登录。授权网页使用该沙箱浏览器。

在另一台电脑上使用

首页点“局域网访问”，检测本机地址，开启后保存并应用。点“查看连接信息”复制地址与口令。远端可操作整个桌面；HTTP 不加密，仅用于可信局域网，不做公网转发。

需要已有 JDK、Maven 或 Node？

选中项目后切换“本机开发”。CCBOX 需要保持打开；每条本机命令先显示完整内容，由你确认一次才执行。Claude 登录与模型继续在容器；普通 Bash 仍在容器，不会透明改成本机命令。首次启用后新建 Claude 会话或重新连接 ccbox-host MCP。

本机模式的权限

本机命令与项目脚本拥有当前用户权限，可能读取系统信息、凭据文件及其他目录，输出可进入模型上下文。本机命令使用本机网络，不自动继承模型代理。工作目录不是系统隔离。切换账号、项目、模式或关闭 CCBOX 会断开本机通道并停止托管任务，不回滚已有修改。

日常操作

最小化后点桌面顶部“恢复 VS Code”；编辑器已关闭则回 CCBOX 点“打开 / 恢复 VS Code”。“发送文字 / 图片”在你明确确认后写入沙箱剪贴板，再到沙箱输入框按 Ctrl+V；不会自动发送消息或同步宿主剪贴板。

更新与资料

停止空间保留 Docker 登录卷。Windows 更新时保留 data 和 storage-location.json，将程序与 runtime 合并回原目录；Mac 替换 App，保留 Application Support 和钥匙串。工具数据、系统保险库、Docker 卷和项目需分别备份。现有桌面环境启用本机模式无需重建；旧沙箱缺组件时按“检查与修复”提示保存工作后升级。

签名与验证范围

Mac 为原生 ARM64，当前 ad-hoc 签名、未 Apple 公证；Windows 未 Authenticode 签名。首次打开请核对来源与 SHA-256，按系统提示确认，不要关闭整体安全检查。CI 检查单元测试、打包与解压后的 GUI 自检；不包含真实账号登录、付费模型请求、完整 Docker 链路或真实 Mac 钥匙串持久化。
